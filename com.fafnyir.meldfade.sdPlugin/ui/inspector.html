Match this to the normal opacity in Meld. Groups fade their visible children together; the folder itself must stay visible. Press again to reverse.

Connection & recovery

In Meld, enable Settings → Advanced → WebSocket Server. Use the default address when both apps run on this computer.

Recovery after an interrupted fade: sets opacity to the value above and makes the chosen layer visible immediately.

Fades affect this layer’s picture. Audio is not faded. A hidden parent group can still hide the layer.
